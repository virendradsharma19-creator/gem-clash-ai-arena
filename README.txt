Gem Clash: AI Arena v1.0.6 — PWA Starter

This package preserves the v1.0.5 game and its confirmed Play Again fix, and adds the missing
Progressive Web App files (manifest, app icon, and service worker) for install/offline support.

HOW TO TEST ON YOUR COMPUTER
1. Extract this ZIP.
2. Open index.html to check the game locally. The browser-install/offline features will not work
   from a file:// address; that is normal.
3. For install testing, the folder must be hosted on an HTTPS website (or localhost).
   After opening the hosted game in Chrome/Edge, use the browser's Install app option if shown.

ANDROID
Open the HTTPS game address in Chrome on the phone. Use the browser menu / Install app or
Add to Home screen when offered.

IPHONE / IPAD
Open the HTTPS game address in Safari. Tap Share, then Add to Home Screen.

IMPORTANT
- This is still a browser game/PWA package, not a signed native APK or iOS App Store build.
- The game uses scripted computer opponents; this does not add online multiplayer.
- App-store submission requires additional native packaging, testing, developer accounts and signing.
- Keep your v1.0.5 ZIP as a backup.
